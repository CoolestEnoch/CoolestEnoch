# 把docker所有镜像容器都迁到sd卡上：
把`/var/lib/docker`目录下的东西全部拷贝到sd卡目录下，然后在`/etc/docker/daemon.json`添加节点：`"data-root":"/home/me/docker/var_lib_docker"`。

``` json
{
        "data-root":"/home/me/docker/var_lib_docker",
        "proxies": {
                "http-proxy": "http://192.168.1.98:2080",
                "https-proxy": "http://192.168.1.98:2080"
        }
}
```
