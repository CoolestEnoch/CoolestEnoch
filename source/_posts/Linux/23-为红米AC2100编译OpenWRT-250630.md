# TL;DR
在23年下半年的某一天，我一个室友给我安利了这台路由器，但我~~*嫌他贵*~~就没买。后来想象可惜，24年上半年想玩的时候发现下架了！淦，现在又想玩了，就上网上二手收了一台。这个机器是`MIPS`架构的，RAM和硬盘都只有`128MB`。对的，是MB，你没看错。确实能买更好的机器，但这个机器拿来练手还是很不错的。


# 思路
先给机器降级，然后利用旧版系统漏洞刷入`Breed`，通过Breed来刷入OpenWRT。因为Breed这个bootloader会在你无法开机或手动进入的时候，起一个`192.168.1.1`的webui用来让你救转/刷入新系统。


# Breed
我们先系统降级，下载[固件包](http://cdn.cnbj1.fds.api.mi-img.com/xiaoqiang/rom/rm2100/miwifi_rm2100_firmware_d6234_2.0.7.bin)，再到路由器后台的手动升级里安装这个老版本系统就行。对的没错，小米这个路由器系统做的还算人性化，可以在系统更新里降级系统。


## 检查硬盘坏快情况(可选操作)
毕竟是二手收来的，成色全靠抽。我这台有三个坏快，淦。。
把电脑通过网线插到路由器的LAN口，进入路由器后台获取你的STOK，替换掉下面的`CCCCCCCCCCC`，然后打开这个连接，等待一会儿，你的路由器名字会变成`Toshiba`或者`ESMT`，后面有可能会接上数字，这个数字就是坏快所在盘块：

## 刷入Breed
Breed我是在b站[这个视频](https://www.bilibili.com/video/BV1114y1X7TA)简介里获取到的。
这段链接是刷入Breed的：
``` url
http://192.168.31.1/cgi-bin/luci/;stok=CCCCCCCCCCC/api/misystem/set_config_iotdev?bssid=Xiaomi&user_id=longdike&ssid=%0Acd%20%2Ftmp%0Acurl%20-o%20B%20-O%20https%3A%2F%2Fbreed.hackpascal.net%2Fr1286%2520%255b2020-10-09%255d%2Fbreed-mt7621-xiaomi-r3g.bin%20-k%20-g%0A%5B%20-z%20%22%24(sha256sum%20B%20%7C%20grep%20242d42eb5f5aaa67ddc9c1baf1acdf58d289e3f792adfdd77b589b9dc71eff85)%22%20%5D%20%7C%7C%20mtd%20-r%20write%20B%20Bootloader%0A
```
这个刷入链接引用了外部URL，如果你家网络不是特别好，个人建议先下载下来然后部署一个web服务器，把固件传上去，然后获取内网链接，替换掉它刷入链接里的链接和`sha256sum`值就行。

> 如果路由器在60秒内重启则代表刷BREED成功(灯会从蓝变橘，最终变蓝进入系统)。
> 如果没重启，可能是stok过期了。进入后台复制新的stok即可。也有可能下载的BREED损坏，重新运行代码，或考虑本地起一个web服务器。


## 手动进入Breed
拔掉电源，按住reset同时接上电源等10秒即可进入breed。需要注意的是如果闪蓝灯那就是BREED。


# 编译OpenWRT系统
## 装依赖
我的环境是`Arch Linux`，所以只要下载一个`AUR`里的包`openwrt-devel`即可，或者也可以手动安装：
``` shell
pacman -S --needed base-devel bash bzip2 git libelf libxslt ncurses openssl rsync swig time unzip util-linux wget which zlib
```
如果你是Debian系发行版，安装这些依赖：
``` shell
sudo apt install build-essential clang flex bison g++ gawk gcc-multilib g++-multilib gettext git libncurses5-dev libssl-dev python3-setuptools rsync swig unzip zlib1g-dev file wget
```


## 准备源码并选择分支
### 从0初始化
下载官方源码：
``` shell
git clone https://git.openwrt.org/openwrt/openwrt.git
# 或者用ImmortalWRT分支: https://github.com/immortalwrt/immortalwrt
cd openwrt # 如果用了上面那个分支, 就是 cd immortalwrt
git pull
```
查看所有分支：
``` shell
git branch -a
git tag
```
切换到指定分支(以`25.12`为例)：
``` shell
git checkout openwrt-25.12
```

### 如果你本地已经有源码，需要拉取当前分支最新更改（以25.12为例）
获取最新分支：
``` bash
git fetch origin openwrt-25.12
```
切换到官方分支：
``` bash
git switch openwrt-25.12
```
更新到最新提交：
``` bash
git pull --ff-only origin openwrt-25.12
```


### 关于切换分支
#### 切换分支后同步`.config`的修改
保存diff：
``` bash
./scripts/diffconfig.sh > ../config-25.12.diff
```
切换分支后，把这个diff拿回来，然后直接`make menuconfig`即可，会自动处理依赖关系，并清理已经不存在的配置选项：
``` bash
cp ../config-25.12.diff .config
make defconfig
```
> 如何检查最新的`.config`是否按照你保存的diff来生成？
> 再跑一遍`./scripts/diffconfig.sh > ../config-new.diff`然后对比这两个diff是否一致即可



#### 切换到另一个大版本分支（以24.10为例）
获取远程分支信息
``` bash
git fetch origin --prune
git branch -r
```
确认列表中存在：
``` bash
origin/openwrt-24.10
```
第三步：首次切换到 24.10
``` bash
git switch --track -c openwrt-24.10 origin/openwrt-24.10
```
这条命令会创建本地 `openwrt-24.10` 分支，并将它关联到远程的同名分支。
以后再次切换时，只需要：
``` bash
git switch openwrt-24.10
git pull --ff-only
```


#### 切换到纯SNAPSHOT
切换到纯 SNAPSHOT 使用：
``` bash
git fetch origin --prune
```
首次切换：
``` bash
git switch --track -c master origin/master
```
以后再次切换：
``` bash
git switch master
git pull --ff-only
```

./scripts/feeds update -a

## 编译
### 修改配置
先初始化一下
``` shell
make defconfig # 全新初始化或切换分支后的仓库首次编译需要执行
make menuconfig
```

把前三行分别改成这样：
``` config
# 红米AC2100改成这样
Target System (MediaTek Ralink MIPS)  --->
Subtarget (MT7621 based boards)  --->
Target Profile (Xiaomi Redmi Router AC2100)  --->

# 磊科N60Pro改成这样
Target System (MediaTek ARM)  --->
Subtarget (Filogic 8x0 (MT798x))  --->
Target Profile (Netcore N60 Pro)  --->
```

### 开始编译
``` shell
make -j$(nproc) download world
```
> 注意⚠️：
> 编译期间会联网下载依赖和部分源码包，请保证首次编译时网络畅通。
> 添加`V=s`参数可以打印详细编译日志而非简单改要。
> 如果你在容器里使用`root`账号跑编译，请设置环境变量`FORCE_UNSAFE_CONFIGURE=1`，不然GNU tar会报错叫你别用管理员账号。

### Docker注意🐳
如果你在docker里跑编译，可能会遇到`fakeroot`卡住的问题，表现是编译进行到 `libgcc1` 软件包打包阶段后，长时间没有后续输出。


具体修复方法是，对源码进行patch然后重新跑编译。


定位到文件`build_dir/host/fakeroot-1.37.1.2/faked.c`找到这段源码：
``` c
#ifdef HAVE_CLOSE_RANGE
# ifdef FAKEROOT_FAKENET
      close_range(0, sd-1, 0);
      close_range(sd+1, num_fds, 0);
# else /* !FAKEROOT_FAKENET */
      close_range(0, num_fds, 0);
# endif
      if (errno == ENOSYS) {
#endif /* HAVE_CLOSE_RANGE */

      /* This is the child closing its file descriptors. */
      for (fl= 0; fl <= num_fds; ++fl)
# ifdef FAKEROOT_FAKENET
   if (fl != sd)
# endif /* FAKEROOT_FAKENET */
     close(fl);

#ifdef HAVE_CLOSE_RANGE
     }
#endif /* HAVE_CLOSE_RANGE */
```
换成这段：
``` c
#ifdef HAVE_CLOSE_RANGE
# ifdef FAKEROOT_FAKENET
      if (close_range(0, sd-1, 0) < 0 ||
          close_range(sd+1, num_fds, 0) < 0) {
# else /* !FAKEROOT_FAKENET */
      if (close_range(0, num_fds, 0) < 0) {
# endif /* !FAKEROOT_FAKENET */
#endif /* HAVE_CLOSE_RANGE */

      /* This is the child closing its file descriptors. */
      for (fl = 0; fl <= num_fds; ++fl)
# ifdef FAKEROOT_FAKENET
        if (fl != sd)
# endif /* FAKEROOT_FAKENET */
          close(fl);

#ifdef HAVE_CLOSE_RANGE
      }
#endif /* HAVE_CLOSE_RANGE */
```

随后回到`immortalwrt`的项目根目录：
``` bash
# 重新编译 Fakeroot
make -C build_dir/host/fakeroot-1.37.1.2 -j1

# 将修复后的程序安装到 staging_dir
make -C build_dir/host/fakeroot-1.37.1.2 install
```

测试一下修复后的fakeroot是否正常工作：
``` bash
timeout 5s staging_dir/host/bin/fakeroot /bin/true
echo "Exit code: $?"
```
正常情况下应该返回：`Exit code: 0`


随后重新跑上面的编译命令即可。


# 刷入系统
编译产物会放在`/project_root/bin/targets/ramips/mt7621`下。
此时，我们将路由器重启到`Breed`，在`固件更新`界面里将`闪存布局`选为`小米 R3G OpenWRT`，然后上传`kernel1`和`rootfs0`即可。

> 注意⚠️：
> 刷机前记得做备份，在`Breed`的`固件备份`里。

## 无线中继
### 启用无线中继
在`Network - Wireless`里，`radio0`是`2.4GHz`的，因为是`802.11b/g/n`；`radio1`是`5GHz`的，因为是`802.11ac/n`。根据你的需求，选择要中继网络的频段，点`scan`，勾选`Replace wireless configuration`和`Lock to BSSID`，然后在`WPA passphrase`里输入密码，随后一路`Submit`和`Save`即可，最后`Save & Apply`。

### 停止无线中继
还是在`Network - Wireless`里，把添加中继的网络全部`Remove`掉，然后在`radio_`右边点`Add`，在`Interface Configuration`里选择`Network`为`LAN`，配置好5GHz频段wifi的ESSID、密码等安全设置后，保存即可。

## ZRAM-SWAP
> 注意⚠️
> 需要你在编译时启用了`kmod-zram`内核模块，不然会安装报错。
> 路径：`Kernel modules > Other modules > kmod-zram`

也是在`System - Software` 里，下载`zram-swap`这个包并安装即可。
或者在 `Base system > zram-swap`
注意，他默认zram大小是内存的一半，对于这种小内存机器肯定不够用，我是搬的安卓上那一套，80%左右的zram，所以需要去修改配置文件。
编辑`/etc/init.d/zram`这个文件，找到这一段：
``` shell
if [ -z "$zram_size" ]; then  
    # e.g. 6mb for 16mb-routers or 61mb for 128mb-routers  
    echo $(( ram_size / 2048 ))
else
```
看到那个`2048`了吗？把它改成`1280`，保存后重启，这样就能启用80%大小的zram，~~*就跟安卓机一样*~~

## 增强防火墙规则
> 注意⚠️：做完这里的所有操作后记得重启防火墙`service firewall restart`生效。


### TTL 128
安装`iptables-nft`这个包，以便方便兼容iptables语法修改防火墙规则。
创建`/etc/nftables.d/12-mangle-ttl-128.nft`，并写入以下规则：
``` nftables
chain mangle_postrouting_ttl128 {
  type filter hook postrouting priority 300; policy accept;
  counter ip ttl set 128
}

chain mangle_prerouting_ttl128 {
  type filter hook prerouting priority 300; policy accept;
  counter ip ttl set 128
}
```

然后就能在`Status - Firewall`里看到这条新增的规则：
****
#### Traffic filter chain "mangle_prerouting_ttl128"
- Hook: **prerouting** (Capture incoming packets before any routing decision), Priority: **300**
- Policy: **accept** (Continue processing unmatched packets

| Rule matches                                                                         | Rule actions                         |
| ------------------------------------------------------------------------------------ | ------------------------------------ |
| 20.4 KB<br><br>Traffic matched by rule: 191 Packets, 20.4 KBytes<br><br>_Any packet_ | Set header field _ip.ttl_ to **128** |
****

### WAN口禁止Ping
往`/etc/nftables.d/10-block-wan-ping.nft`写入文件：
``` nft
chain block_wan_ping {
    type filter hook input priority -1; policy accept;

    # 阻止 WAN 入站 IPv4 Ping
    iifname $wan_devices ip protocol icmp icmp type echo-request counter drop

    # 阻止 WAN 入站 IPv6 Ping
    iifname $wan_devices meta l4proto ipv6-icmp icmpv6 type echo-request counter drop
}
```

# 番外：磊科N60Pro相关
## 准备：原厂系统
把电脑插到LAN口，注意要插在千兆口上。然后进入路由器后台`192.168.0.1`，在OOBE中设置的无线上网密码同时是后台登录密码和ssh密码。进入后台后在`应用 - 远程访问`中 打开ssh。随后连接到路由器的22端口，用户名`useradmin`，密码就是你在OOBE设置的。


## 备份原厂分区
先查看一下分区表：
``` bash
useradmin@N60PRO:~# cat /proc/mtd
dev:    size   erasesize  name
mtd0: 08000000 00020000 "spi0.1"
mtd1: 00100000 00020000 "BL2"
mtd2: 00080000 00020000 "u-boot-env"
mtd3: 00200000 00020000 "Factory"
mtd4: 00200000 00020000 "FIP"
mtd5: 07280000 00020000 "ubi"
```
> mtd0:SPI分区
> mtd1:引导分区
> mtd2:U-BOOT分区
> mtd3:校准分区 <- 这个分区每台机器都不一样，千万保存好！
> mtd4:FIP分区
> mtd5:系统分区

然后把它们全部dd出来：
``` bash
useradmin@N60PRO:~# dd if=/dev/mtd1 of=/tmp/mtd1_BL2.bin
2048+0 records in
2048+0 records out
useradmin@N60PRO:~# dd if=/dev/mtd2 of=/tmp/mtd2_ubootenv.bin
1024+0 records in
1024+0 records out
useradmin@N60PRO:~# dd if=/dev/mtd3 of=/tmp/mtd3_Factory.bin
4096+0 records in
4096+0 records out
useradmin@N60PRO:~# dd if=/dev/mtd4 of=/tmp/mtd4_fip.bin
4096+0 records in
4096+0 records out
useradmin@N60PRO:~# dd if=/dev/mtd5 of=/tmp/mtd5_ubi.bin
234496+0 records in
234496+0 records out
```
> 注意：路由器原厂系统是没有`sftp`的，你得用U盘给他拷出来。


## 刷入并进入U-Boot（相当于红米的Breed）
先准备好uboot文件，从[这里](https://drive.wrt.moe/uboot/mediatek/mt7986-netcore_n60-pro-fip.bin)下载。随后这样刷入：
``` bash
mtd write /path/to/uboot.bin FIP
```
> 对的是刷到`fip`分区，别搞错了！！！
> 在[`drive.wrt.moe`](https://drive.wrt.moe)上还有个`fip-fit`的固件，别刷那个，刷没有`-fit`的！！！

随后将路由器关机（要断电），然后用卡针顶住底部的reset键别松开，然后再给路由器上电，保持8秒不松手，等前面板电源灯变成缓慢闪烁的蓝色后松手。此时路由器已进入第三方uboot。确保电脑插在千兆LAN口上，电脑进入`192.168.1.1`即可。


## 刷入系统
在第三方uboot后台，点刷入固件，按界面提示刷入`sysupgrade`即可，刷入完成后路由器会自动重启进入新系统。
> 注意：此处不建议用firefox系浏览器，因为`UPDATE COMPLETED`回调可能被拦截。
