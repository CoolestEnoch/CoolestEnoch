# 去除通知栏的x和！
删除原有的captive portal地址
``` shell
adb shell settings delete global captive_portal_https_url  
adb shell settings delete global captive_portal_http_url
```
添加新的地址
``` shell
# 小米服务器
adb shell settings put global captive_portal_https_url https://connect.rom.miui.com/generate_204
adb shell settings put global captive_portal_http_url http://connect.rom.miui.com/generate_204
```
这里列一些其他的地址，按自己爱好选择。
``` text

cp.cloudflare.com/generate_204
www.qualcomm.cn/generate_20
```


# 相册不刷新问题
``` shell
adb shell pm clear com.google.android.providers.media.module
adb shell pm clear com.android.providers.media
adb shell am broadcast -a android.intent.action.MEDIA_SCANNER_SCAN_FILE -d file:///storage/emulated/0/DCIM
```


# NTP慢
``` shell
# 设置中国时区
adb shell setprop persist.sys.timezone Asia/Shanghai
# 设置NTP服务器
adb shell settings put global ntp_server ntp1.aliyun.com
```
这里列一些其他的地址，按自己爱好选择。
``` text
time.asia.apple.com
time.windows.com
time.cloudflare.com
```
