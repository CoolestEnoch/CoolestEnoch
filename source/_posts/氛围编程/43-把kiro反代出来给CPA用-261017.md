# 提OAuth2 Token
kiro不像codex，他把OAuth2 Token放在本地的sqlite数据库里。以下是各平台的数据库目录。
``` text
Linux:
~/.local/share/kiro-cli/data.sqlite3
macOS:
~/Library/Application Support/kiro-cli/data.sqlite3
（部分版本也在 ~/.local/share/kiro-cli/data.sqlite3）
Windows:
%LOCALAPPDATA%\Kiro-Cli\data.sqlite3
（%LOCALAPPDATA% 是 C:\Users\<你的用户名>\AppData\Local）
```


接下来用你喜欢的`sqlite`编辑器打开它，找到`auth_kv`这个表，把它dump一下，你就能看到你的登录OAuth2 Token了。以笔者电脑为例，运行这个命令即可：
``` bash
sqlite3 ~/.local/share/kiro-cli/data.sqlite3 -cmd ".mode column -limits off -sw auto" -cmd ".mode quote" "SELECT key, value FROM auth_kv;"
```
随后便能看到这个OAuth2 Token：
``` SQL
'kirocli:social:token','{"access_token": "xxxxxxx","expires_at": "20xx-xx-xxxxxxxx","refresh_token": "xxxxxxx","telemetry_generation": "xxxxxxx","provider": "github","profile_arn": "arn:aws:xxxxx:us-east-1:xxxxxx:profile/xxxxxx"}'
```
其中这段`json`就是你的OAuth2 Token：
``` json
{"access_token": "xxxxxxx","expires_at": "20xx-xx-xxxxxxxx","refresh_token": "xxxxxxx","telemetry_generation": "xxxxxxx","provider": "github","profile_arn": "arn:aws:xxxxx:us-east-1:xxxxxx:profile/xxxxxx"}
```
保存好~~*放一边备用*~~。


# 配置`kiro-rs`
## 后台配置文件
创建`config.json`：
``` json
{
  "host": "127.0.0.1",
  "port": 8990,
  "apiKey": "sk-114514",
  "adminApiKey": "1145141919810",
  "tlsBackend": "rustls",
  "region": "us-east-1"
}
```

> 管理员登录面板和CPA共用8990端口。
> 这里的`apiKey`是CPA接入时的key，`adminApiKey`是webui管理员面板的登录密码。
> 这里的`region`按上面`profile_arn`里的来写，一般都是`us-east-1`你不用管它。


## kiro账号配置文件
创建`credentials.json`：
``` json
[
  {
    "id": 1,
    "accessToken": "填写上面的access_token",
    "refreshToken": "填写上面的refresh_token",
    "profileArn": "填写上面的profile_arn",
    "expiresAt": "填写上面的expires_at",
    "authMethod": "social"
  }
]
```


# 开跑
直接向`kiro-rs`传递两个参数即可。
``` bash
./kiro-rs -c config.json --credentials credentials.json
```

> `kiro-rs`会遵守环境变量里的代理配置


# 接入CPA
在`AI提供商`里新建`Claude`，API密钥就写上面的`apiKey`，服务地址写`http://127.0.0.1:8990`即可。
