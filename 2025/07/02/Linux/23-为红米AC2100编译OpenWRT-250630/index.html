为红米AC2100编译OpenWRT


(封面图源小米商城)

TL;DR

在23年下半年的某一天，我一个室友给我安利了这台路由器，但我嫌他贵就没买。后来想象可惜，24年上半年想玩的时候发现下架了！淦，现在又想玩了，就上网上二手收了一台。这个机器是MIPS架构的，RAM和硬盘都只有128MB。对的，是MB，你没看错。确实能买更好的机器，但这个机器拿来练手还是很不错的。

思路

先给机器降级，然后利用旧版系统漏洞刷入Breed，通过Breed来刷入OpenWRT。因为Breed这个bootloader会在你无法开机或手动进入的时候，起一个192.168.1.1的webui用来让你救转/刷入新系统。

Breed

我们先系统降级，下载固件包，再到路由器后台的手动升级里安装这个老版本系统就行。对的没错，小米这个路由器系统做的还算人性化，可以在系统更新里降级系统。

这个刷入链接引用了外部URL，如果你家网络不是特别好，个人建议先下载下来然后部署一个web服务器，把固件传上去，然后获取内网链接，替换掉它刷入链接里的链接和sha256sum值就行。

手动进入Breed

拔掉电源，按住reset同时接上电源等10秒即可进入breed。需要注意的是如果闪蓝灯那就是BREED。

后续

修改网段

在Network - Interfaces - LAN里，点编辑，把IPv4 addres改掉就行，记得遵循局域网ip段的规则哦～

校园网没法弹出上网认证

在Network - DNS - Filter里关闭Rebind protection。

无线中继

启用无线中继

在Network - Wireless里，radio0是2.4GHz的，因为是802.11b/g/n；radio1是5GHz的，因为是802.11ac/n。根据你的需求，选择要中继网络的频段，点scan，勾选Replace wireless configuration和Lock to BSSID，然后在WPA passphrase里输入密码，随后一路Submit和Save即可，最后Save & Apply。

停止无线中继

还是在Network - Wireless里，把添加中继的网络全部Remove掉，然后在radio_右边点Add，在Interface Configuration里选择Network为LAN，配置好5GHz频段wifi的ESSID、密码等安全设置后，保存即可。

美化

进入菜单：System - Software ，先更新列表，然后下载并安装luci-theme-argon即可，主题就会自动变好看。
Argon主题的管理面板：下载luci-app-argon-config这个包即可，随后即可在System - Argon Config里管理主题，比如登录页面背景。

或者直接编译进系统，这样可以免去开机再下载:

如果sshfs第一次运行没反应，在命令后面添加参数-d -o debug,sshfs_debug,loglevel=debug然后看看是什么原因，基本都是首次连接没有信任主机

刷回原厂

在Breed里的固件更新，闪存布局选择小米 R3G 原厂，只把miwifi_rm2100_firmware_d6234_2.0.7_breed.bin上传到固件里，刷入后等待重启，随后在小米系统里进行一次系统更新，就能把Breed清除，彻底回到小米系统。

番外：磊科N60Pro相关

准备：原厂系统

把电脑插到LAN口，注意要插在千兆口上。然后进入路由器后台192.168.0.1，在OOBE中设置的无线上网密码同时是后台登录密码和ssh密码。进入后台后在应用 - 远程访问中 打开ssh。随后连接到路由器的22端口，用户名useradmin，密码就是你在OOBE设置的。

备份原厂分区

先查看一下分区表：

mtd0:SPI分区
mtd1:引导分区
mtd2:U-BOOT分区
mtd3:校准分区 <- 这个分区每台机器都不一样，千万保存好！
mtd4:FIP分区
mtd5:系统分区

然后把它们全部dd出来：

注意：路由器原厂系统是没有sftp的，你得用U盘给他拷出来。

刷入并进入U-Boot（相当于红米的Breed）

先准备好uboot文件，从这里下载。随后这样刷入：

对的是刷到fip分区，别搞错了！！！
在drive.wrt.moe上还有个fip-fit的固件，别刷那个，刷没有-fit的！！！

随后将路由器关机（要断电），然后用卡针顶住底部的reset键别松开，然后再给路由器上电，保持8秒不松手，等前面板电源灯变成缓慢闪烁的蓝色后松手。此时路由器已进入第三方uboot。确保电脑插在千兆LAN口上，电脑进入192.168.1.1即可。

刷入系统

在第三方uboot后台，点刷入固件，按界面提示刷入sysupgrade即可，刷入完成后路由器会自动重启进入新系统。

注意：此处不建议用firefox系浏览器，因为UPDATE COMPLETED回调可能被拦截。
